### Цель и брендинг
- **Концепция:** Чистый UI — воздух, крупная типографика, продукт в центре.
- **Брендинг:** айдентики нет. На этапе 4 собираем вордмарк ALYMP, палитру OKLCH, шрифт с кириллицей.
- **Референсы — первостепенные:** apple.com, tesla.com, dji.com — эстетика, типографика, воздух, скролл-подача продукта.
- **Референсы — второстепенные:** robort.ru, unitree.ru, gumanoids.ru — структура категорий, B2B/B2C-подача роботов.
- **Дизайн-система:** shadcn/ui (стандарт для Next.js). Подбор `kickoff` не выполнен: нет доступа к NikitOS `Library/`. Выполним после подключения.
- **Шаблон сайта:** кандидат для лендингов — `scroll-world` + `gsap`. Решение — на этапе 4.

### Стек (по «Юрисдикция и стек», РФ)
- Стартер `nikalimp/ai-ready-starter`: Next.js, статическая сборка, контент в репозитории (`content/`).
- Хостинг: тест — `alymp.nikalimp.ru` (REG.RU, deploy-kit). Прод — хостинг в РФ.
- Формы: данные хранятся в РФ.
- Новости и блог: публикация коммитом в GitHub → GitHub Actions (`website-publish`).

Внутренняя перелинковка — главный рычаг SEO-слоя:
- лендинг → термины глоссария, бренд, сравнения, новости бренда;
- термин → товары, где технология есть;
- новость и статья блога → товар и термины.

### Механики SEO-слоя (детали — в spec)
1. **Глоссарий.** Термин по шаблону: определение в первом абзаце (прямой ответ до 50 слов), как работает, где встречается (товары ALYMP), сравнение с соседним термином, FAQ. Генерация — пачками через контент-завод, проверка фактов по источникам.
2. **Новости.** GitHub Actions по расписанию читает RSS и разделы новостей брендов. Отбрасывает дубли. Пишет русский пересказ со ссылкой на источник. Открывает PR, PR сливается сам. Дословный перевод не публикуем — только пересказ своими словами (авторское право). Картинки — только из пресс-китов.
3. **Сравнения.** Программные страницы из одной таблицы характеристик (`content/products/*.json`). Сравнения и характеристики берут данные из неё.
4. **Блог.** Контент-завод по стандарту: рубрики, план, публикация по будням.
